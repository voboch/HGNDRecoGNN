# Detector-only inference parity on historical SMASH

The next simulation with a compatible detector export is needed to measure response transfer. On the accepted 2.87 GeV/nucleon Xe+CsI simulation, the earlier reconstruction opened MC associations to verify hit identity and reject any half-event containing a hit with PDG zero. The audit found zero such vetoed hits in the 286 exact-bound even files. This experiment checks that the same reconstruction can be executed from detector observations alone on that population.

The plan pins raw hits, legacy truth exports for the separate reference, actual held-out fold and its B pack, train-fitted scalers, original GNN checkpoints and the registered classifier cut. The detector path reads only the observed hit columns. It applies the same 3 MeV deposit threshold, finite-field check, deterministic 150 ps simulated smearing and detector side mask. It builds the original graphs with the original scalers and runs the same rules + ToF selection. It must reproduce hit ordering and bytes, native graph features, topology, candidates, event/side keys, the pinned processed spans, including zero-hit events inferred by subtraction, and the rules + ToF candidate lists. The legacy branch independently reproduces the published full observation hash.

The first file in content order for each actual held-out fold is the witness. On each, CPU forwards compare the selected classification and raw energy checkpoint outputs for seeds 42, 123 and 456, using the same platform, batch size and architecture on both sides. A controlled PDG-zero injection must change only the legacy observation, by the predicted half-event hit count. Injected extra truth columns on the detector input must be ignored. The three witnesses are checked before processing the other files. Witness decision counts use the registered classifier predicate and the inherited energy bands. The full file census checks graphs and rules outputs. Network forwards are compared on the three witnesses. No parameters are fit.

The thesis Methods section on neutron reconstruction will cite this result if accepted.

The job runs once on rocky/normal, 4 CPUs, 0 GPUs, two workers, at most 45 minutes, with no requeue. A discrepancy fails the job and preserves its work directory. Exact parity establishes that legacy production on this historical population can be replayed without truth fields at inference. It establishes neither response transfer to the updated SMASH simulation nor closure of the (R_n) bias. No new odd-file outcomes, classifier cuts or calibrations are computed.
