# Приёмка экспорта предсказаний SMASH

Распаковать скачанный архив в локальный каталог. Для каждого из 18 заданий нужны квитанция `score_SCOPE_TASK_JOB.json` и одноимённый каталог с `manifest.json` и `inputs.tar`. Сохранить исходный архив и журналы в каталоге загрузки.

Запуск из каталога `HGNDRecoGNN`.

```bash
python reports/smash_architecture_20261112/accept_score_exports.py \
  results/smash_architecture_20261112/score_even_download --scope even \
  --extract results/smash_architecture_20261112/score_even_accepted
```

При наличии полученного от источника списка `sha256sum` для 18 квитанций передать его через `--receipt-sums PATH`. В списке указываются имена квитанций без каталогов. Приёмка сохраняет SHA-256 каждой квитанции в обоих случаях и сверяет этот хеш со списком, если он задан.

Для нечётных файлов указать `--scope odd`, отдельный выходной каталог и `--odd-release PATH --odd-release-sha256 PUBLISHED_SHA256`. Приёмка сверяет хеш допуска во всех нечётных экспортах. Файл frozen policy передаётся при редукции.

`acceptance.json` появляется после проверки всех 18 заданий. Из поля `prediction_bundles` передать каждый путь отдельным аргументом `--prediction-bundle`. Приёмка сверяет SHA-256 файлов, список TEST и пустых файлов, эпохи обеих голов и пороги с принятыми fit. Она проверяет численные поля CSV, уникальность ключей `(Row, ClusterID, cl_istop)`, число кандидатов и нативных положительных меток. Редуктор сверяет ключи, метки, истинную энергию и размеры кандидатов с GraphSAGE. [Редукция](reduction.md)
