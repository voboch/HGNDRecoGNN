## M1 — Нативная классификация и обнаружение первичного нейтрона имеют разные знаменатели

Источник: `classification.pooled` и `direct_association.pooled.by_stage_and_truth_range`. На 1 798 225 кандидатах, включая 322 058 нативно-положительных, ROC-AUC равен 0.954377517 / 0.956423825 / 0.953865559 для GraphSAGE / DynamicEdgeConv / hetero; SD трёх seed равен 0.000023249 / 0.000063255 / 0.000136400. Это метрика нативных меток кандидата, не эффективность обнаружения геометрического первичного MC-нейтрона.

В истинном диапазоне 0.3–4 ГэВ исходное прямое покрытие одинаково: 27.293205146%. Это свойство общей сегментации. После raw70 score и `0.3 < E_reco < 4` оно равно 21.681959001 / 21.926266520 / 21.614915273%. Парная разность к GraphSAGE составляет +0.244307519 п.п. для DynamicEdgeConv, файловое SD 0.008010439, Q16–Q84 [0.236380410, 0.252349592]; для hetero −0.067043729 п.п., SD 0.008298329, интервал [−0.074890243, −0.057988191]. Следовательно, допустим вывод о небольшом изменении отбора уже существующих связей.

## M2 — Сеть не исправляет исходное слияние

В той же истинной полосе `all` доля split среди MC равна 5.599677984%, merge среди кандидатов — 0.317869010%. При score-only отборе split равен 1.164986918 / 1.223773818 / 1.134195828%, merge — 1.514382783 / 1.503062397 / 1.521055811%. Различные знаменатели обязательны в подписи. Рост доли merge после отбора не означает создание новых слияний: состав выбранных кандидатов изменился. Ни одна из трёх моделей не может разделить замороженный кандидат. Не следует называть снижение выбранной доли merge исправлением сегментации.

## M3 — Снижение MAE не означает улучшение всех характеристик энергии

Источник: `matched_energy.preselection.primary`. На общих 160 537 изолированных связях в истинном диапазоне 0.3–4 ГэВ MAE равен 91.264249775 / 88.616242356 / 93.952832482 МэВ. Парная разность DynamicEdgeConv к GraphSAGE: −2.648007420 МэВ, файловое SD 0.157239590, Q16–Q84 [−2.787312476, −2.481765381]. Для hetero: +2.688582707 МэВ, SD 0.101894754, интервал [2.582271183, 2.790329549].

Однако медиана относительной ошибки равна −1.167065180 / −1.611673657 / −1.156289433%, а центральная полуширина относительной ошибки — 5.197706679 / 5.212983292 / 5.571375889%. Формулировка «DynamicEdgeConv улучшает разрешение» без уточнения метрики неприемлема: поддержано снижение MAE при более отрицательной медиане и близкой центральной ширине. Парные изменения MAE по seed равны −1.481341692, −4.376091897 и −2.086588671 МэВ; файловое SD не заменяет этот разброс обучения.

Источник `matched_energy.common_selected.primary` даёт общие численности 119 508 / 119 571 / 119 631 по seed и MAE 84.153101979 / 81.785947463 / 85.376246247 МэВ по моделям. `own_selected` имеет разные наборы и служит условной диагностикой. Его нельзя использовать как изолированный эффект регрессии. Выше 4 ГэВ сохраняется ограничение хвоста: до отбора имеется 789 связей в 4–5 ГэВ, 68 в 5–6.5 ГэВ и ноль выше 6.5 ГэВ. Медианы в 5–6.5 ГэВ равны −17.585747 / −17.869305 / −18.623887%; нулевой последний бин означает неоценимость.

## M4 — Выбор рабочей точки не является оценкой её обобщения

`frozen_policy.selected_targets` фиксирует 90 / 75 / 90% по знаковому среднему контрасту 90/0 на even. Общий потолок `ceiling_file_sd_pp=2.487437819249382` равен удвоенному SD GraphSAGE raw70 `1.243718909624691`. Это зарегистрированное ограничение разброса, не физический допуск на смещение. Полная сетка сохранена в `scan`; повторно выбирать по odd нельзя. Основное сравнение остаётся raw70. 400 общих целофайловых реплик при фиксированных моделях и три training seeds описывают разные неопределённости. Три фолда не дают девять независимых повторов обучения. Зарегистрированный парный seed-анализ с Holm относится к будущему odd-сравнению и здесь не подменяется файловыми интервалами.

## Границы принятого вывода

Общий бюджет 30 эпох не равен общему GPU-времени: README сообщает 34.43 GPU·ч для DynamicEdgeConv и 49.56 для hetero. Возможные минимумы на границе бюджета не доказывают глобальную оптимальность архитектур. Результат относится к общей SMASH-продукции и фиксированным кандидатам; независимый физический отклик не проверен. Исторический Dombay остаётся отдельным незакрытым вопросом происхождения весов и преобразований; современный DynamicEdgeConv его не воспроизводит.

Следующий шаг уже предусмотрен планом: применить замороженную политику к odd, затем переносить поддержанные числа в канонический отчёт и рукопись. Новых экспериментов или дополнительных ворот приёмки это ревью не вводит. **GO относится к even-отчёту; окончательная оценка метода для статьи и нечётные выводы остаются открытыми.**

### Первичный исход: выигрыш по абсолютному смещению контраста не разрешён

В raw70 для открытой жёсткой полосы MC-контраст 90/0 равен 4.95256%. Реконструированные контрасты GraphSAGE / DynamicEdgeConv / hetero равны 2.60549 / 2.82872 / 2.68846%, файловые SD — 1.19038 / 1.13766 / 1.20856 п.п. Остатки к MC составляют −2.34708 [−3.50369, −1.21649], −2.12384 [−3.17409, −1.06095] и −2.26411 [−3.50475, −1.10062] п.п. Таким образом, точечный контраст у всех трёх ниже MC. Парное изменение абсолютного остатка к GraphSAGE равно −0.22324 [−0.57824, +0.11426] п.п. у DynamicEdgeConv и −0.08297 [−0.39248, +0.31309] у hetero. Ни один интервал не исключает нуль.

Проверены `seed_test`, `adjust_holm` и `hardness` в reducer. Файловый анализ берёт модуль после среднего контраста по seed внутри реплики; seed-тест берёт разность модулей отдельно для каждого seed на исходных файлах. Это разные зарегистрированные estimands. Для основного raw70, open 90/0, DynamicEdgeConv имеет среднюю разность −0.223236275 п.п., SE 0.214416639, t=−1.041133167; hetero −0.082969992 п.п., SE 0.051119813, t=−1.623049615. df=2; нескорректированные p равны 0.407140156 и 0.246054090, Holm p=0.492108179 для обоих. Два сравнения образуют заранее заданную семью. Три seed дают ограниченную мощность; отсутствие обнаруженного преимущества не устанавливает эквивалентность. Дополнительный seed-блок secondary в JSON не меняет первичную семью гипотез и не должен подаваться как новый подтверждающий тест.

### Вторичная процедура: меньший файловый разброс имеет цену

Замороженные цели 90 / 75 / 90% дают открытый 90/0 контраст 4.19114 / 3.55027 / 3.01234%, SD 2.16112 / 1.28836 / 2.37880 п.п. DynamicEdgeConv имеет меньший файловый SD, но его центральный остаток −1.40230 п.п. дальше от MC, чем −0.76142 у GraphSAGE. Парное изменение абсолютного остатка +0.64088 [−1.63033, +1.04554] п.п. не разрешено по файлам. Это сравнение полных процедур с разными выбранными целями, поэтому весь эффект нельзя приписать архитектуре. Близость GraphSAGE к MC также не доказывает физическое замыкание: его остаток имеет широкий интервал [−2.79755, +1.49005] п.п.

Уточнение M3: pooled относительная ширина в 0.3–4 ГэВ не улучшилась, однако изменения по истинным энергетическим бинам неоднородны; например, в 4–5 ГэВ ширина DynamicEdgeConv 8.625154% против 9.139299% у GraphSAGE. Поэтому также недопустима обратная широкая формулировка «улучшения разрешения нет нигде». Граница 4 ГэВ ограничивает сравнительную полосу; она не является физическим пределом ToF.

Итоговый поддержанный вывод: при общей сегментации DynamicEdgeConv повышает покрытие и снижает условную MAE, но принятое сравнение не разрешает преимущества по абсолютной точности контраста жёсткости.
