# Жёсткость нейтронов на нечётных файлах

На 1 165 216 общих событиях из 282 нечётных файлов SMASH Xe+Cs при
2,87 ГэВ на нуклон сравниваются правила + ToF, GNN с порогом,
выбранным по контрасту на чётных файлах, и геометрические первичные
нейтроны MC. Порог соответствует цели 90% нативной чистоты на
валидации. Применены девять ранее зафиксированных порогов по
fold и seed и сохранённая калибровка энергии. Для каждого файла
используется модель, при обучении которой этот файл был исключён.
Нечётные файлы исключены из выбора цели, их базовые результаты
уже изучались.

В каждом событии учитываются все кандидаты, прошедшие отбор. Обработанные диапазоны
сохраняются и для событий с нулём кандидатов. Энергия относится к
кандидату для реконструкций и к первичному нейтрону для MC truth.
Для $R_n=N_{\rm hard}/N_{\rm soft}$ мягкая полоса — $[0{,}3,1)$ ГэВ,
со строгим порогом $E>0{,}3$ для реконструкций. В 846 сохранённых
таблицах предсказаний строгое неравенство не меняет ни одного счётчика
мягкой полосы. Открытая жёсткая полоса $E\ge2$ ГэВ совпадает с
критерием выбора порога. Дополнительный вариант $2\le E<4$ ГэВ
ограничен номинальным диапазоном ToF. Сравнение относится к
кандидатам до коррекций фона и спектра. [Протокол](protocol.md)

Контраст $C_{a/b}=100[R_n(a)/R_n(b)-1]$ сначала вычисляется внутри
каждого seed после суммирования файлов. Центр GNN усреднён по трём
seed. Для всех методов и пар используются одни 400 файловых
перевыборок со стратификацией по потенциалу и номеру части.
Парные разности считаются внутри каждой реплики. Разность абсолютных
отклонений — $|C_{\rm GNN}-C_{\rm MC}|-|C_{\rm rules}-C_{\rm MC}|$. Полуширина
$(Q_{84}-Q_{16})/2$ описывает разброс по файлам при фиксированных
моделях. Три пары коррелированы.

Для 90/0 в открытой полосе GNN даёт 3,76% при 2,05% у правил и
4,95% у MC. Парные сдвиги от MC равны −1,19 [−3,29; +1,05] п.п.
и −2,90 [−4,21; −1,81] п.п. соответственно. Полуширина GNN
2,17 п.п. почти вдвое больше, чем 1,10 п.п. у правил.
Во всех трёх парах и обоих диапазонах центральный контраст GNN
ближе к MC и его полуширина больше. Интервалы парной разности
абсолютных отклонений от MC во всех шести случаях включают ноль.

## Хвост и воспроизведение

Энергии $E\ge4$ ГэВ дают 30 298 кандидатов правил (26,5% открытой
жёсткой полосы), 1 588–1 619 кандидатов GNN на seed (около 2,3%)
и 4 593 геометрических первичных нейтрона MC (2,1%).
Исключение хвоста сохраняет порядок центральных отклонений от MC
и ширин, хотя его вклад в число жёстких кандидатов заметно зависит
от метода.

Задание 4502690 завершилось с кодом 0:0 за 6:05. Опубликованный
архив включает 282 файла и сводку. Наблюдения для 5 751 796 хитов
побитово воспроизвели принятый вход, а счётчики первичных частиц
совпали по каждому событию. Подсчёт ограничен теми же диапазонами Row.
Экспорт GNN и девять порогов переиспользованы. Парные значения в
открытой полосе точно воспроизводят принятую сводку GNN и MC.
