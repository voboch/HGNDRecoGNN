# Выгрузка импульсов и быстроты · этап A

17 ноября 2026. [Экспортёр](../../scripts/export_smash_rapidity.py) формирует отдельный NPZ `smash-rapidity-kinematics-v1` на каждом принятом чётном файле. В нём есть весь сохранённый событийный инвентарь и маска рабочего диапазона. Для нейтронов в принятом реестре и MC-протонов геометрического окна присутствуют `Px/Py/Pz`, `E`, `Ekin`, `Mass`, вершина, экспортная и рассчитанная быстрота. Сохраняются лабораторная и НН-быстрота с принятым сдвигом 1,0392525 для этой продукции. Исходные веса генератора в проверенных первичных CSV отсутствуют. Приведённые числа являются счётчиками объектов.

В режиме с хитами и графами сохраняются ключи, координаты, направления и оба времени выбранного хита. Для rules + ToF и трёх разрешённых seed DynamicEdgeConv импульсы рассчитаны из сохранённой реконструированной энергии и детекторного направления. Для сети направление в этом пилоте задаётся первым хитом по оригинальному времени, как в прежней диагностике ToF. Для оценки отклика в экспериментальных условиях следует явно проверить направление при выборе по измеряемому времени. При отсутствии физического ToF энергии, импульсы и быстроты соответствующих кандидатов правил помечены как недоступные.

На локальном PyTorch при повторной записи наблюдений меняется контейнер. Сравнение с исходным файлом с принятым SHA подтвердило совпадение массивов. Содержимое двоичного элемента `data/0` совпало побайтно. Локальная версия добавляет метаданные формата и выравнивания. В режиме без исходного файла экспортёр требует совпадения SHA повторной записи наблюдений. При наличии оригинала проверяет его SHA и значения массива. Guard для native labels/targets действует в обоих режимах.

Результаты сохранены в `results/rapidity_export_20261117`. [Квитанции с исходными SHA и результаты сверок](validation.json). Независимый критик дал GO для полного пилота по значениям наблюдений, ключам и привязке трёх seed и указал на необходимость проверки укороченного диапазона. Финальная локальная сверка дополнительно проверила такой файл и сдвиг в НН-систему. Это приёмка состава и связности данных на двух файлах.

Запуск для одного файла из `HGNDRecoGNN`:

```sh
python scripts/export_smash_rapidity.py --content bigSpot/10943245/0001 \
  --primary /path/to/pinned_primary.csv --vacs /path/to/pinned_vacs.csv \
  --hits /path/to/pinned_hits.csv --pack /path/to/pinned_native.pt \
  --observation /path/to/pinned_observation.pt \
  --dynamic-scores results/smash_architecture_20261112/score_even_accepted \
  --output /path/to/new/output
```

Для кинематики первичных частиц достаточно `--content`, `--primary`, `--vacs` и `--output`. Первый полный кандидатный NPZ занимает 2,49 МБ. Измеренное локальное время обработки скачанного файла — 1,07 с без импорта библиотек и передачи по сети.
